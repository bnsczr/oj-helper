直接打开 Friends standings，读取该页完整榜单并保存为 standings.md，在 VS Code 中打开。保留所有行、全部题目列、排名、罚时或得分及评分变化，比赛结束后同样完整保留。开启上方选项时包含非正式参赛者。

添加题目快捷键

在 Codeforces 题目页或比赛 Dashboard 按 Shift+N，执行与 + 相同的添加操作，页面提示“正在添加…”和“更新完成”。输入框或代码编辑器中不触发，以免影响输入大写 N。更新扩展后请刷新题目页。
