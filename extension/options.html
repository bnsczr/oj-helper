先在终端运行 submit --pair，将显示的配对码粘贴到这里。

新建题目文件（CF / QOJ）

保存目录需填写已有文件夹的绝对路径，没有默认路径。例：E:\code\CF。两站的题号关联、语言选择和最近题面分别保存；同一保存目录中的同名源码仍会覆盖。

只需一次性安装浏览器连接，之后点击 + 会自动启动助手，依次分配 A.cpp、B.cpp 等文件并更新对应题号，无需常驻终端。

比赛模式

开启后会补建缺少的空 C++ 文件，并在 VS Code 打开对应源码。已有文件保留原内容。

open b 好友榜单

CF 打开 Friends standings，QOJ 打开比赛页的 Extra/External Standings，读取完整榜单并保存为 standings.md，在 VS Code 中打开。保留所有行、全部题目列、排名、罚时或得分及评分变化。Show unofficial 仅用于 CF。

添加题目快捷键

在 Codeforces 或 QOJ 题目页、比赛 Dashboard 按 Shift+N，执行与 + 相同的添加操作，页面提示“正在添加…”和“更新完成”。输入框或代码编辑器中不触发，以免影响输入大写 N。更新扩展后请刷新题目页。
