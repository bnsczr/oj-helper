# oj-helper

编辑器右上角 **+**，以及资源管理器中 **oj-helper** 面板右上角 **+**，均可新建题目文件。

先打开 VS Code 设置，搜索 `codeforcesHelper.directory`，填写保存目录的绝对路径，例如 `E:\code\CF`。没有默认目录，未配置时会提示并提供“打开设置”。目录需已存在。

点击 + 后输入 `2278F`，即可创建并打开 `2278F.cpp`。也支持 `1A`、`123B1` 或 `1A.cpp`。同名文件已存在时打开原文件，不覆盖。取消输入不会创建文件。

扩展会从本项目或 Path 中的 oj-helper 安装目录读取 `oj CF` / `oj qoj` 选择。QOJ 模式接受数字题号或题目网址，例如 `123`、`https://qoj.ac/contest/42/problem/123`，创建并打开 `123.cpp`，同时记录该文件的 QOJ 提交目标。题面、PDF 和样例导入仍使用浏览器 + 或 Shift+N；此手动入口与原 CF 功能一样创建空文件。

没有打开编辑器时，可以使用资源管理器里的 oj-helper 面板，或命令面板中的“oj-helper: 新建题目文件”。

这是命令行提交工具的配套 VS Code 扩展；提交仍使用现有 `submit` 命令及浏览器扩展。
